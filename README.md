# Pizzeria Trejo

## Requisitos
- PHP 8+
- MySQL o MariaDB
- Servidor web compatible con PHP

## Variables de entorno para Railway
Configura estas variables en Railway:
- DB_HOST
- DB_PORT
- DB_NAME
- DB_USER
- DB_PASS

## Pasos
1. Crea la base de datos MySQL y ejecuta el contenido de database.sql.
2. Sube estos archivos a tu repositorio.
3. Despliega en Railway usando el servicio PHP.
4. Accede a index.php para ver la landing y usar el login.
